The mechanics

Free, fast, and never noisy.

The engineering that makes shared memory cost $0 in API calls and never waste a token on irrelevant context.

ADD-only writes, duplicate-guarded

A cosine similarity guard blocks near-duplicates on write — no per-fact LLM judging loops burning API calls. Conflicts resolve at read time by recency.

Similarity-gated injection

Weak matches inject nothing. A per-session ledger guarantees a fact is never injected twice. Memory that wastes tokens isn't memory — it's noise.

Three-signal retrieval

HNSW vector search + FTS5 keywords + entity matching, fused with Reciprocal Rank Fusion — on a dedicated facts index that never pollutes document search.

Cache-stable injection

Facts are injected as a byte-stable, cache-aligned block — ordered by immutable id, volatile timestamps stripped. The prefix stays identical across sessions, so the host model reads its prompt cache (0.1×) instead of re-writing it (1.25×).

Honest about savings

psyche mem stats reports measured cache behavior straight from your Claude Code transcripts, and separates host-cache context from what's attributable to Psyche. No headline "saves you X%" — the honest, attributable effect is cost-avoidance versus a cache-busting design, not a blanket discount.

Experiential learning · v0.8

A memory store that gets better.

Psyche captures outcome signals so the store improves over time — bad or stale facts get removed, and the system records which facts were present when sessions went well versus badly.

  • Outcome capture Each session is classified good / bad / neutral and scored against the exact facts that were injected. A per-fact daily cap stops one noisy session from skewing the signal.
  • Permissioned forgetting Soft-retire memories (hidden from retrieval, not deleted), hard-delete after review, or unforget to restore. Learning means being able to forget what no longer matters.
  • Check-in auto-scoring Experiments with a numeric success condition are scored deterministically against your latest logged metric — no model judgment required.
  • See it working psyche mem outcomes is an observability window into the whole loop — totals, top facts by win-rate, and forget candidates.

Honest by design: the frontier model's weights do not change. What improves is the quality of the stored context. Ranking on outcome counters is deliberately not enabled yet — this release is capture & forgetting only, and the view labels every number as observed signal, not causal proof.

Stateful agent memory · Letta / MemGPT hierarchy

Not a search box — a memory system.

Five tiers of memory your agents read and write dynamically, instead of treating RAG as a static lookup.

1

Document Knowledge search_knowledge

Hybrid FTS5 (BM25) lexical + HNSW vector search over all your files.

2

Core Memory write_memory_core

Key-value facts and project guidelines the agent writes and reads on the fly.

3

Archival Memory append_memory_archival

Vector-embedded logs, learnings, and debugging context for long-term reference.

4

Interaction History record_interaction

Stateful logging of conversation turns for context persistence across sessions.

5

Atomic Memory add_memory · search_memories

Deduplicated one-sentence facts with agent scope and entity links — injected automatically, shared cross-agent.
